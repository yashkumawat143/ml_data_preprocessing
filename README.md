# ML Data Preprocessing

This repository contains datasets used for **Machine Learning and Data Preprocessing practice**.

## 📂 Datasets

The repository contains different datasets for practicing various data preprocessing and machine learning techniques.

Some of the concepts include:

- Handling missing values
- Data cleaning
- Encoding categorical variables
- Feature scaling
- Feature transformation
- Handling outliers
- Train-Test Split
- Column Transformer
- Machine Learning Pipelines
- Data visualization

## 🎯 Purpose

The main purpose of this repository is to practice **Data Preprocessing and Machine Learning concepts using Python**.

These datasets can be used to understand how raw data is cleaned, transformed, visualized, and prepared before applying Machine Learning algorithms.
